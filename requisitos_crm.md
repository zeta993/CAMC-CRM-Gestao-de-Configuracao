\# CAMC CRM – Sistema de Gestão de Relacionamento com Clientes



\## Objetivo

Desenvolver um sistema para centralizar o relacionamento da CAMC com seus clientes.



\## Requisitos funcionais



1\. Permitir o cadastro de clientes.

2\. Registrar o histórico de compras e atendimentos.

3\. Permitir a abertura e o gerenciamento de tickets.

4\. Centralizar os canais de atendimento, como WhatsApp, e-mail e telefone.

5\. Controlar o status das solicitações dos clientes.

6\. Permitir o registro de avaliações e feedbacks.



\## Requisitos não funcionais



1\. O sistema deve possuir interface simples e intuitiva.

2\. O acesso deve ser controlado por usuários autorizados.

3\. Os dados dos clientes devem ser armazenados com segurança.

4\. O sistema deve permitir a consulta organizada das informações.



\## Contexto

A CAMC necessita melhorar a organização dos dados dos clientes e centralizar os atendimentos, substituindo controles dispersos por uma solução integrada.
